# Cinetic Konsept

[Cinetic Creatives](https://cinetic-creatives.com/) sitesinin Next.js App Router ve TypeScript ile hazırlanan konsept çalışması.

Ana sayfa giriş filmini, sürüklenebilir galeriyi, kaydırmayla geçiş yapan üç kategori filmini ve etkileşimli alt logoyu içerir. Proje arşivinde kategori seçimi, sayfalama ve küçük resim üzerinden video sarma vardır. Hakkında, Hizmetler, Sinema ve proje detayları kendi rotalarında açılır.

## Yerelde çalıştırma

```sh
npm ci
npm run dev
```

Tarayıcıda [localhost:3000](http://localhost:3000) adresini açın. Üretim derlemesi için `npm run build`, TypeScript kontrolü için `npm run typecheck` çalıştırın.

Giriş ve kategori filmleri ile proje kapakları yerel dosyalardan sunulur. Uzun filmler ve bazı görseller kaynak siteden yüklenir. Görsel kimlik ve proje medyası Cinetic Creatives'e aittir. Zalando Sans Expanded yazı tipinin lisansı [OFL.txt](public/fonts/OFL.txt) dosyasındadır.
